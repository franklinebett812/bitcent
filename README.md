# CryptoVault — One Page Crypto Investment Website

A responsive crypto investment landing page built with plain HTML, CSS and JavaScript.

## Run in VS Code
1. Open the folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. No build step or Node.js is required.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — menu, modal, FAQ and authentication form interactions

## Important
This project uses Firebase Authentication configuration in the JavaScript file for the account login workflow.
